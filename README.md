# 阿爾卡納 Arcana Sky

塔羅異世界的瀏覽器小遊戲。不用註冊、不用安裝，打開就能玩。

**從共同首頁進入：https://edchriswu.github.io/tarot-journey/**

| 遊戲 | 網址 | 說明 |
|---|---|---|
| 我來異世界可不想再成為塔羅師 | https://edchriswu.github.io/tarot-journey/story/ | 視覺小說遊戲。跟著綾走過赤原、澄湖、風城、金穗谷，踏上愚人之旅；約 30 分鐘，可以分次走完。 |
| 來異世界找塔羅師 | https://edchriswu.github.io/tarot-journey/ （共同首頁的「大眾占卜」） | 帶一個問題來，讓綾為你抽三張牌。 |

- 進度、暱稱和問題只存在你自己的瀏覽器裡，不會傳到任何伺服器。
- 字型和程式都放在這個網站裡，不連到其他網站。

## 檔案結構

- `index.html`、`data.js`、`data/`、`img/`：共同首頁與《來異世界找塔羅師》
- `story/`：《我來異世界可不想再成為塔羅師》
- `fonts/`、`lib/`：兩款遊戲共用的字型與 QR code 產生程式

## 圖片與字型

- 塔羅牌面：Pamela Colman Smith 繪、A. E. Waite 設計，1909 年 Rider 版，公有領域。
- 區域封面、人物肖像、人物立繪：作者自製。
- 字型：芫荽（Iansui）、思源宋體（Noto Serif TC）、Great Vibes、Alex Brush，皆為 SIL Open Font License。
- QR code 產生程式：qrcode-generator（Kazuhiko Arase，MIT License）。
