# 我來異世界可不想再成為塔羅師

一款塔羅瀏覽器遊戲。一位塔羅師在異世界醒來，走過赤原、澄湖、風城、金穗谷四塊土地，踏上愚人之旅。

**開始遊戲：https://edchriswu.github.io/tarot-journey/**

- 不用註冊、不用安裝，打開就能玩；一趟約 20 分鐘。
- 進度只存在你自己的瀏覽器裡。
